# Stern SAM to MPF: instructions for Claude

This repository holds the game-agnostic agents and knowledge base for rebuilding a Stern SAM pinball game in
MPF. Start from the master plan below: it says which agent file covers the task at hand. Read only that agent
file and the knowledge docs it names; update it in the same session when you learn something it should say.
Game facts belong in that game's repositories, not here. Every game-agnostic learning comes back here in the
same session, without asking the user: a PR with write access, otherwise a GitHub issue (CONTRIBUTING.md).
